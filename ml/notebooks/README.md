# ML Notebooks

Jupyter notebooks for exploratory data analysis and experimentation.

## Notebooks

- `01_data_exploration.ipynb` - Explore raw FITS files and telemetry
- `02_feature_engineering.ipynb` - Feature extraction and analysis
- `03_model_prototyping.ipynb` - Model architecture experiments
- `04_embedding_visualization.ipynb` - UMAP/t-SNE of embeddings

## Setup

```bash
pip install jupyter pandas matplotlib seaborn
jupyter notebook
```
